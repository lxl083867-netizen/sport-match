| 情况 | 返回值 |
|------|--------|

## 6. 重复操作会出错吗？

逐按钮/操作回答：

- [ ] 同一个按钮连点两次 → 会触发两次操作吗？能拦截吗？
- [ ] 操作进行中刷新页面 → 数据会半写入吗？
- [ ] 浏览器后退 → 会看到过期状态吗？
- [ ] 操作成功后立刻再做一次 → 报错还是静默重复？

---

## 7. 删除操作安全吗？

- [ ] 删除一个东西 → 删除确认弹窗存在
- [ ] 删除后 → 引用了它的其他地方会出现什么？（"视频已失效" / 计数错误 / 外键报错）
- [ ] 删除的不是自己创建的东西 → 按钮不可见或 API 拒绝（403）

---

## 8. 核心流程走一遍

手动（或让 AI 描述）走完完整路径，确认每个节点都能到达：

**流程 A：新用户首次使用**
```
打开首页 → 看到冷启动 CTA → 回答 3 个问题 → 提交 → 看到今日训练方案
```

**流程 B：有收藏的用户日常使用**
```
打开首页 → 看到今日训练方案（来自收藏）→ 点"开始跟练" → 完成 → 反馈 → 回到首页
```

**流程 C：换一个**
```
打开首页 → 点"换一个" → 方案有变化 → 点第 4 次 → 被拒绝
```

**流程 D：创建 + 编辑计划**
```
计划广场 → 创建计划 → 保存 → 查看详情 → 编辑 → 修改标题/调整顺序 → 保存 → 删除
```
