## 5. 四种状态怎么表现？

本次为「可解释性证据」的增量展示，核心改动组件：`TodayPlanCard`、`recommend` 调试页、服务端 `assessPlanQuality`。

| 状态 | TodayPlanCard（evidence） | debug 页 | assessPlanQuality |
|------|---------------------------|----------|-------------------|
| **Loading**（数据加载中） | 沿用现有 loading，不变 | 服务端直出，无前端 loading | 服务端同步计算 |
| **Empty**（无数据） | `evidence`/`quality` 可选，`item.evidence?.field` 兜底，无证据时不渲染 | 无导入视频时显示"暂无导入视频"空态 | 方案为空时产出 critical `empty_plan` |
| **Error**（接口报错） | 本次无新增网络请求，沿用现有 lib/api.ts + Toast | 无 mutation，不产生错误 | 纯读 + 计算，无副作用 |
| **未登录**（无 session） | 服务端页面内，跟随整页鉴权 | `redirect("/auth/login")` | 仅服务端调用，需 userId |

API 状态表：本次无新增 API 端点，不适用。
