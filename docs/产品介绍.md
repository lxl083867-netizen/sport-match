# SportMatch 产品介绍

## 一句话定位

**跨平台运动内容策展引擎** — 把散落在 B站/小红书/抖音的收藏，变成可执行、可追踪、越用越懂你的训练计划。

---

## 解决什么问题

### 用户画像

在社交媒体上频繁刷到运动教程短视频的人。Ta 们：

- 看到运动视频会点收藏，但收藏夹从此变成信息坟场
- 不确定哪个教程真的适合自己——膝盖有旧伤能不能做？大基数能不能跟？
- 缺乏工具把分散在不同平台的视频组织成有结构的训练计划
- 没有记录和追踪，练了等于没练

**核心痛点：收藏即终点。信息过载导致行动瘫痪。**

### SportMatch 怎么做

| 痛点 | 解决方案 |
|------|----------|
| 收藏夹吃灰 | 将收藏行为转化为"加入训练计划"——有序列表 + 跟练模式 |
| 不确定适不适合自己 | 运动画像匹配引擎：根据目标/水平/身体状况/禁忌动作过滤 |
| 无法判断视频质量 | AI 分析评论区真实反馈，自动提取训练标签 |
| 多平台视频无法统一管理 | 支持 B站/小红书/抖音三平台视频统一编入计划 |
| 练了等于没练 | 打卡系统 + 个人数据看板 + 反馈闭环持续优化推荐 |

---

## 核心功能

### 1. 运动画像
注册后引导完成画像设置：运动目标（减脂/增肌/康复/体能/柔韧）、当前水平、身体状况（含禁忌动作）、可用器材、单次训练时长。这是推荐引擎的输入。

### 2. AI 评论分析打标签
自动抓取视频评论，通过 DeepSeek 大模型分析提取结构化标签。例如从"我是大基数，跟这个有点吃力但没伤膝盖"中提取——适用人群：大基数、膝部：安全。标签含置信度 + 证据原文 + 来源。**这是产品最核心的差异化能力。**

### 3. 个性化推荐
基于画像标签与 AI 标签的规则匹配引擎，考虑标签置信度、用户反馈历史、难度适配、禁忌排除。推荐结果附带匹配理由（如"匹配你的目标：减脂""适合零基础人群"），可解释性强。

### 4. 跟练反馈闭环
每次训练后一键反馈：难度感知、身体感受、完成度、是否推荐。反馈数据实时修正推荐权重——越用越懂你。

### 5. 训练计划社区
用户可以创建训练计划（选择视频 + 编排顺序 + 标注阶段 + 添加适用人群标签），公开发布到社区。他人可点赞/收藏/跟练计划。

### 6. 跟练追踪模式
点击"开始跟练"进入专注模式：计时器、进度条、按顺序打卡、全部完成后总结。视频在 B站站内嵌入或跳转原平台观看——SportMatch 是训练搭子，不是播放器。

### 7. 个人数据看板
7 天活动柱状图、周目标打卡环形进度、运动类型分布、最近跟练时间线。将训练行为可视化。

### 8. 深色模式
手动切换或跟随系统，CSS 变量体系确保一致体验。

## 技术架构

| 层 | 技术 | 
|----|------|
| 前端框架 | Next.js 16 (App Router) |
| 样式 | Tailwind CSS + Apple Design System CSS 变量 |
| 数据库 | SQLite (Prisma ORM) |
| 认证 | NextAuth.js v5 |
| AI 管道 | Python + DeepSeek API |
| 设计系统 | Apple Human Interface Guidelines 映射的运动场景 |
